## Name Suggestion Index

`server/oikonome/engine/merchant_seed_data.py` is generated by
`scripts/refresh-merchant-seed.py` from the Name Suggestion Index
(<https://github.com/osmlab/name-suggestion-index>), the OpenStreetMap
community's brand database. The brand names in that file are derived from
it; the generated file records the exact upstream release it came from in
its `NSI_VERSION` constant.
